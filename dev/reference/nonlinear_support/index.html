Nonlinear Support

DynOptInterface.supports_objective_argument — Function
supports_objective_argument(
    model::MOI.ModelLike,
    F::Type{<:MOI.AbstractScalarFunction},
    A::Type{<:MOI.AbstractScalarFunction},
)::Bool

Return a Bool indicating whether model supports objective functions of type F containing one or more arguments of type A.
