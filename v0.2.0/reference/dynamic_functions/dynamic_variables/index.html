Dynamic Variables

DynOptInterface.DynamicVariableIndex — Type
DynamicVariableIndex(value::Int64, phase::DynamicVariableIndex)

An object for use in referencing dynamic variables in a model.

It is a sub-type of AbstractDynamicFunction. It represents a dynamic variable $t_i \mapsto y_j(t_i)$ defined in the domain $[t_i^0, t_i^f]$. The Int64 index value is stored in the value field. To allow for deletion, indices need not be consecutive.

DynOptInterface.UnsupportedDynamicVariable — Type
UnsupportedDynamicVariable(message::String)

An error indicating that dynamic variables are not supported by the model.

That is, that supports_dynamic_variable returns false. The message String is stored in the message field.

DynOptInterface.AddDynamicVariableNotAllowed — Type
AddDynamicVariableNotAllowed(message::String)

An error indicating that dynamic variables cannot be added to the model in its current state.

The String error message is stored in the message field.

Attributes

The DynamicVariableIndex object is compatible with the following attributes:

  • MOI.VariableName with value types String
  • MOI.VariablePrimal with value types AbstractDynamicSolution
  • MOI.VariablePrimalStart with value types AbstractDynamicSolution
